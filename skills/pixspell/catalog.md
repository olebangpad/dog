# PixSpell sprite catalog

Generated by `scripts/build.js`: 304 sprites, 1370 looks with variants,
2,761,072 character combinations. Use a variant by appending its name: `potion` -> `potion-mana`.
Any sprite can also be recolored with `spell(id, { A: 'material' | '#hex' })`.

## Character bodies: `spell.char({ body })`
