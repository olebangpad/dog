# DOG sprite catalog

Generated by `scripts/build.js`: 184 sprites, 851 looks with variants,
2,756,176 character combinations. Use a variant by appending its name: `potion` -> `potion-mana`.
Any sprite can also be recolored with `dog(id, { A: 'material' | '#hex' })`.

## Character bodies: `dog.char({ body })`

Humanoids hold `hand` and `offhand` items and have drawn front / back / side walk poses: `hero`, `skeleton`, `heroine`, `goblin`, `robot`.
Others wear hats only: `dog`, `cat`, `chick`, `slime`, `ghost`, `skull`, `frog` (the dog walks side-on, the rest hop or float).
